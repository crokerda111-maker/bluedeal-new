# 블루딜 6개월 PC 핫딜 조사 프로그램

## 2026-11-21 누락·행사 조건 검토

`python -m ops.hotdeals.gap_review`는 저장된 `catalog-review/candidates.local.json`을 읽고 실행일 기준 최근 6개월 게시 시각 구간과 공개 상품 목록을 대조한다. 네트워크·계정 접근·운영 게시·가격 갱신을 하지 않는다. 결과는 `ops/private/catalog-review/event-audit/review.generated.local.json`으로 재생성하므로 수동 메모는 이 생성 파일에 적지 않는다. 읽은 원장 해시·시각·원래 게시일 정확도를 보존한다.

2026-11-21 실행은 원장 601건 중 기간 내 592건을 선별했다. 래플 9건과 주변기기 분류 재검토 3건을 분리한 일반 판매 후보는 580건이다. 글 수는 고유 제품 수가 아니다. 같은 CPU명이 있는 완본체/반본체를 단품 CPU로 병합하지 않으며 모델 토큰 일치는 정확한 옵션/SKU 확인이 아닌 관련 관리번호 참고값이다. 메인보드·완본체·반본체의 미등록 분류 후보 149건과 묶음·구성 검토 30건을 구분한다. SSD/HDD는 기존 분류가 통합돼 있어 HDD 누락 여부는 별도 재분류가 필요하다.

`event-notes-2026-11-21.json`에는 별도로 읽은 본문 3개와 공식 행사 근거, 마켓별 추가 확인사항을 보관한다. 공식 본문 7개 마켓, 공식 검색 색인만 확보한 롯데ON, 아직 조건이 없는 옥션·아마존·오늘의집을 구분한다. 다음 행사 일정이나 모든 마켓의 중복 할인을 확정한 자료가 아니다. 할인율/쿠폰 코드를 새 행사에 자동 재사용하지 않는다. 현재가·재고·제조사 품번 신규 검증은 0건이며, 새 상품을 자동 게시하지 않는다.

G마켓의 캐시/외부 경유, 네이버의 사후 적립, 알리의 리뷰 보상 등을 결제액과 분리한다. KB Visa 알리 공식 사례는 USD·직접 카드 결제·K-Venue 제외·다른 코드 중복 불가·ID당 1회 조건이 있어 일반적인 알리 중복 할인 공식으로 확장하지 않는다. 외부 캐시백 경유는 블루딜 제휴 귀속 조건과도 별도 대조한다. 쿠팡 현재 블프 발표는 공식 본문과 PDF 배너의 종료일 표기가 달라 확인 대기 상태를 유지한다.

관리용 추가 엑셀은 저장소 밖 `outputs/bluedeal-products-20261121/`의 핫딜 누락·행사 준비 파일이다. 기존 상품관리 엑셀은 덮어쓰지 않는다. 필터·출처·담당·검토 상태·행사 단계별 근거를 남기며 자동 CMS/예약 작업으로 연결하지 않았다. 합성 검사는 `python -m unittest discover -s ops/tests -p test_gap_review.py`로 실행한다.

`홈페이지 구축/핫딜 수집기 시작.cmd`를 더블클릭하면 이 PC의 검토 화면이 열립니다. **6개월 수집 시작 / 이어서 수집**으로 실행하고, **중지** 후에도 마지막 저장 페이지 다음부터 이어받습니다. 창을 닫으면 서버도 종료됩니다. 한 PC에서 중복 수집은 파일 잠금으로 막습니다.

이 도구는 상품 후보를 조사하는 **로컬 프로그램**입니다. 운영 가격표·게시글·제휴 설정은 변경하지 않습니다. 제휴 계정·암호·키·브라우저 로그인 정보도 읽지 않습니다.

- 원문 주소·게시글 번호·제목·게시 시점 표기·수집 시각·게시글 가격/배송 표기·종료 표시를 저장합니다. **제목에 의한 모델/분류는 검토 후보이며 확인된 사양이 아닙니다.**
- 전체 본문·댓글·작성자·닉네임·사용자 식별자·이미지를 수집 DB에 저장하지 않습니다.

- 동일 출처+게시글 번호로 중복을 제거하고, 제목·용량·키트 구성을 보존한 후보 키를 만듭니다. 같은 CPU 이름이 있는 완본체와 CPU 단품을 합치지 않습니다.

이 도구의 요청 범위는 사용자가 지시한 비공개 상품 후보 조사입니다. 수집이 가능하다는 이유로 상업적 공개 활용이나 원문 재게시까지 허용됐다고 판단하지 않습니다. 해당 범위와 출처 표시는 운영 반영 전에 별도로 확인해야 하며, 프로그램은 재게시 기능이나 허가를 대신하는 버튼을 제공하지 않습니다.

다른 출처의 데이터 내보내기 파일이나 적법하게 확보한 HTML은 `import-html`로 분석할 수 있습니다. 파일 몇 개를 가져왔다고 6개월 수집 완료로 표시하지 않습니다. 뽐뿌/쿨엔조이 파서는 합성 데이터로 검사한 구조이며, 실제 접근/구조 검증을 끝냈다고 표시하지 않습니다.

## 준비와 실행

Python 3.10 이상과 Beautiful Soup가 필요합니다. 이 PC에서는 Python 3.13과 Beautiful Soup 4.13.4를 확인했습니다.

```powershell
python -m pip install -r ops/hotdeals/requirements.txt
python ops/hotdeals/server.py --open-browser
```

CLI:

```powershell
# 첫 작업 생성. 실제 사이트 요청 없음
python ops/hotdeals/research.py init

# 접근 조건 확인 후 수집. 각 출처의 제한은 상태에 기록
python ops/hotdeals/research.py crawl

# 같은 작업의 남은 페이지를 재개
python ops/hotdeals/research.py crawl

# 새 기간으로 시작 (이전 작업/자료는 보존)
python ops/hotdeals/research.py crawl --new --since 2026-05-18 --until 2026-11-18

# 확보한 UTF-8 HTML의 일부를 분석. 실제 확보 시각 필요
python ops/hotdeals/research.py import-html --source quasarzone --input PATH_TO_SAVED_HTML --observed-at 2026-11-18T22:00:00+09:00

python ops/hotdeals/research.py status
python ops/hotdeals/research.py report
# 파서 분류를 개선한 뒤 저장 자료를 다시 해석 (수집 시각/현재가를 갱신하지 않음)
python ops/hotdeals/research.py reclassify
python -m unittest discover -s ops/tests -p test_hotdeals.py
```

요청 간격은 기본 3초이며 robots의 더 긴 간격을 우선합니다. 한 번에 출처당 최대 1,500페이지를 읽고 멈추며 재개할 수 있습니다. HTTP 401/403/429·구조 변경·동일 페이지 반복·robots 제한을 발견하면 해당 출처를 중단합니다. 두 연속 페이지가 기간보다 오래됐거나 실제 목록 끝에 도달했을 때만 기간 탐색 종료로 기록합니다. 날짜 미상 행이 있으면 별도 검토 상태가 됩니다. 삭제/비공개 글이나 전체 인터넷의 완전성을 보장하지 않습니다.

목록에 월·일만 있을 때는 최근 과거 날짜의 연도를 보완했다고 명시합니다. 퀘이사존의 기간 경계에서는 실제 글의 JSON-LD 게시 시각을 읽어 연도를 별도로 확인하며, 댓글 날짜는 사용하지 않습니다. 확인되지 않으면 전체 기간 충족으로 처리하지 않습니다. 생략된 제목은 게시글별로 분리해 보이지 않는 옵션을 하나로 합치지 않습니다. 추첨/래플과 복수 상품 모음은 단일 구매 가격으로 사용하지 않습니다.

## 결과와 검토

Git에서 제외된 `ops/private/hotdeal-research/` 안에 저장합니다.

- `hotdeals.sqlite3`: 게시글/관측값/진행 상태
