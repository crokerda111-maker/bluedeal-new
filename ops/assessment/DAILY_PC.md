# 오늘의 완본체·반본체

운영 가격 화면에서 한국 시각 기준 당일 판매 기록을 읽는다. Vercel 정기 실행은 매일 오전 10시 시간대(KST)에 이뤄진다. 컴퓨존 조립PC 메인관의 선택형 DIY를 제외한 반본체·완본체 링크를 매번 확인한다. 예약 요청은 운영 환경의 `CRON_SECRET`으로 인증하고, 결과는 날짜별로 45일간 저장한다. 작업 중복을 방지하며 스냅샷 저장 후에만 당일 결과를 노출한다.

수집기는 판매 상세의 상품 번호, 수량 1 판매가, 두 합계, 기본 본체 배송비, 기본 부품표를 대조한다. 부품 박스 배송과 쿠폰·회원·카드 혜택은 별도 조건이다. G마켓·11번가의 robots.txt는 일반 예약 수집기를 허용하지 않으므로 허용된 API 또는 피드를 확보할 때 추가한다.

## 비교와 부품 평가

- 완본체는 CPU와 GPU 모델·VRAM 기준으로 묶으며, 반본체는 CPU 기준에 외장 GPU 제외 조건을 붙인다. 그래픽카드 용량으로 구성 차이가 나는 모델은 용량 확인이 필요하다.
- 배송 포함 일반가로 정렬한다. 같은 급·OS·보증에서 두 개 이상 비교하면 비교군 최저 관측가를 표시한다.
- 메인보드 25%, 파워 25%, RAM 15%, 저장장치 15%, 쿨러 12%, 케이스 8%를 부품 평가에 배정했다. 부품표·정확한 모델·호환·보증과 이슈 적용 상태가 확인된 구성끼리 종합 점수를 낸다. 가격 점수는 같은 급의 비교 가능한 최저 금액을 기준으로 `최저가 ÷ 해당 금액 × 60`을 계산하고 부품 평가를 40점 만점으로 더한다.
- 공식 자료 체크리스트와 독립 측정은 출처 및 확인일을 기록한다. 모델명이 같아 보여도 리비전·용량·전원 규격이 불명확하면 보류한다. 점수와 제휴 수수료는 독립적이다.
- 검토한 구성은 `src/content/pcBuildReviews.json`에 추가한다. 매칭에는 당일 선택 조합의 지문(`configuration`), 판매자 부품 상세 지문(`detailDigest`), 부품별 표기, 호환·이슈 검토가 필요하다. 판매 옵션 또는 상세가 바뀌면 다시 검토한다.
- 동일 부품 직접 구매 비용은 부품 전체, 주문별 배송, 조립, OS, 보증을 확인한 뒤 비교한다. 가격 화면에는 직접 입력 계산기도 연결되어 있다.

개발 검증은 `node --experimental-strip-types --test ops/tests/daily-pc.mjs`를 사용한다. 운영 모집단 크기, 수집 중단, 당일 건수는 상품 비교 화면에서 확인한다.
